# New Risk Migration Dashboard

This folder contains a fresh standalone dashboard project.

## Files
- `index.html` — the new dashboard layout, styles, and inline chart script.

## How to use
1. Open `new-dashboard/index.html` in your browser.
2. The dashboard renders using the embedded sample dataset.
